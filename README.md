# 🎓 Students API - RESTful Web Service

This is my first RESTful API project built using **ASP.NET Core Web API**.  
It manages student data using a layered architecture with Business Layer, Data Access Layer, and DTOs.

---

## 🚀 Project Overview

The system provides basic CRUD operations for students, along with additional analytical endpoints such as:

- Get all students
- Get passed students
- Get student by ID
- Add new student
- Update existing student
- Delete student
- Calculate students average grade
